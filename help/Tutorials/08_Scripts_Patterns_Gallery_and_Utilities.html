Tutorial 8: Scripts: Patterns, Gallery and Utilities

Written 6 November 2026 for Sketchpad on branch claude/tier-a. Files and functions are named rather than given line numbers, so the text stays right as lines move: in VS Code press Ctrl+P to open a file and Ctrl+Shift+O to jump to a function, or look it up in docs/FUNCTIONS.md. "Watch it" lines use the browser's developer tools (F12): Sources to set a breakpoint, Console to run a line.

Most of your own drawing work is scripts: patterns, gallery scripts, utilities and the Ideabook hints. They all run through one script runner. This tutorial covers the runner, writing each kind of script, the playpen and promotion rule, Script history and the Ideabook.

8.1 The script runner

Read

ui/scriptRunner.js: loadScriptModule, executeScriptToCanvas, executeScriptToText, normalizeScriptInfo, buildControlsIfPresent, runScriptByPath.

What happens

A script is a module that exports runPattern(). loadScriptModule(path) imports it fresh each time (a time stamp on the address), so an edit in VS Code runs as saved. executeScriptToCanvas puts drawState back as it was at load (resetDrawStateForScript), clears the canvas, starts the time-limit clock, runs runPattern(), stops the clock, then reads the script's scriptInfo (normalizeScriptInfo): if it is interactive its handles are armed, and if it has controls they are built. executeScriptToText is for utilities that return HTML.

8.2 Writing a pattern script

Read

Any short script in patterns/ (for example patterns/fundamental/), then a longer interactive one.

What happens

A pattern exports runPattern() and usually a scriptInfo describing its parameters and controls, so the runner builds sliders and calls the script again on each change. It draws through drawLine (or the drawing helpers), so Final mode, stepping and the time limit apply. Header comments at the top become its Notes.

Watch it

Open a pattern, caption menu > Show Script.

Try

Copy a small pattern, give it one slider through scriptInfo, and save it into a patterns folder: it appears in the list at once (tutorial 13).

8.3 Gallery scripts: the playpen and promotion

Read

gallery/Scripts/ (any folder); CLAUDE.md, the promotion rule.

What happens

Gallery scripts are where ideas are tried, freely, with their own copies of routines if need be (several carry the old intersection search). They are never promoted as they are: reusable code is pulled into draw/, you minimise it, and only then does it become a registry object.

Watch it

Open gallery/Scripts/Curve Stitch/manyRowsColumns.js, the best example of exploration.

Try

Pick a routine a gallery script defines for itself and find its cleaner equivalent in draw/ (shapers, connectors, curves or intersections).

8.4 Utilities: Tools and Lab

Read

ui/utilities/ (utilities.js, utilitiesDisplay.js runUtilityEntry, displayUtilityResult); utilities/Tools and utilities/Lab.

What happens

Utilities are scripts too. Tools are maintenance jobs (Show Logs, Validate Draw Registry, Thumbnails); Lab holds experiments. Some draw; others return HTML, which is shown in #text (the Result subtab).

8.5 Script history

Read

ui/scriptHistory.js (openScriptHistory, fillPanel, showDiff); node/scriptHistoryRequests.mjs.

What happens

VS Code keeps earlier saved versions of files. Script history lists them for a script, and lets you run any version or compare it with the current one, line by line. Nothing is written: it only reads VS Code's history folder.

Watch it

Edit a pattern in VS Code twice, saving each time, then caption menu > Script history.

Try

Find in node/scriptHistoryRequests.mjs where the history folder is looked for on Windows.

8.6 The Ideabook

Read

ui/caption.js (the extra Run script button), gallery/Ideabook/<category>/scripts/, gallery/Ideabook/scripts/ideabookRoutines.js and pursuitEngine.js.

What happens

Each Ideabook image may have a hint script named after it (with & , # ? % + ; written as _). The caption's Run script button runs it. The hints are sketches of how the picture might be built, using shared routines written StringThing's way: defaults for everything, nothing refused, all through drawLine. The pursuit engine is kept in its own file because it is to become a draw function.

Watch it

Gallery > Ideabook > Pursuit, open an image, press Run script.
