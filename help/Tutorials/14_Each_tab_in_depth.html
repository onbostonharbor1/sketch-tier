14.1 Home: state, Categories, Results

Read

ui/home/home.js (HomeTabSpec, initHomeTab, restoreHomeTab, ensureHomeSavedState), homeState.js (incrementHomeResultsRenderToken), homeNav.js, homeResults.js (renderHomeResults, isImagePath, deriveHomeOriginFromPath), homeMenuCmds.js.

What happens

Home remembers its view and the item open in uiState.home.saved. Categories shows one frame per status. Clicking an item either shows it in Results (a script runs on the canvas, a picture shows in #text) or launches another tab (a Draw object, a figure). Results uses a render token: each render takes a number, and a slow earlier render that finishes late sees its number is out of date and does nothing, so you never see the wrong item.

Watch it

Click two Home items quickly and watch the token in the debugger.

Find where a Draw object item launches the Draw tab.

14.2 Home's newer subtabs

Read

ui/home/homeErrors.js, homeChecklist.js (parseChecklist), homeHelp.js (renderHomeHelp, reflectionFileName), homeNotes.js, homeTickList.js (renderTickList); node/homeListRequests.mjs.

What happens

Errors and Checklist share one list display: checkboxes, Show all, Purge ticked, and for the checklist Add item. Errors are read from the logs (tutorial 17); the checklist is home/checklist.md, rewritten whole through writeChecklist. Help is a jsTree of four groups (Design, Reflections, Build Documents, Tutorials) beside a page pane; New reflection writes a page and opens the help editor. Notes shows home/notes.md.

14.3 The alert bar

Read

ui/homeAlert.js (showHomeAlert, parseMaintenanceSummary).

What happens

On Home, a yellow bar appears when errors are not yet ticked, or when the last manifest check found problems; each part has its own Dismiss, remembered for the present count or log.

14.4 Draw as a tab

Read

ui/draw/draw.js, drawNav.js, drawMenuCmds.js (wireDrawCommandsButton), drawCategories.js.

What happens

Draw keeps a subtab per open object, marks changed ones, validates saved-settings subtabs whose files have gone, and has a Maintenance panel. Its restore path rebuilds the subtab bar and shows the active object as left.

Watch it

Open three objects, switch tabs, come back.

Try

Read validateOpenSecondaryTabs and say when it closes a subtab.

14.5 Patterns

Read

ui/patterns/patterns.js (PatternsTabSpec, initPatternsTab, restorePatternsTab, rehydratePatternsState), patternsNav.js, patternsDisplay.js (renderPatternThumbGrid, showSelectedPattern, onPrev, onNext), patternsMenuCmds.js, patternsState.js.

What happens

Patterns lists categories, shows a picture grid for a category, runs a pattern on the canvas with its caption and controls, and steps with Prev and Next (wrapping round). The caption menu has Help, Show Script, Script history, Edit Manifest, thumbnail and Archive.

14.8 Figures as a tab

Read

ui/figures/figures.js (FiguresTabSpec, setFiguresAction), figuresNav.js (subtabs, addCaptionTools, updateFigureButtons), figureLayerPanel.js (renderLayerPanel), figuresCommands.js, figuresDisplay.js, figuresState.js.

What happens

The Figures tab has a Categories subtab (saved figures and Create Figure) and a subtab per open figure. The caption carries the tools (Line, Parabola, the shape palette, Curve, Template, the active layer's name and Show). The left column holds Show All, Points Mode and Insert, all tab-extra. The number strip shows the layers in their colours; clicking one makes it active.
