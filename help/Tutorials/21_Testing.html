Tutorial 21: Testing

Written 6 November 2026 for Sketchpad on branch claude/tier-a. Files and functions are named rather than given line numbers, so the text stays right as lines move: in VS Code press Ctrl+P to open a file and Ctrl+Shift+O to jump to a function, or look it up in docs/FUNCTIONS.md. "Watch it" lines use the browser's developer tools (F12): Sources to set a breakpoint, Console to run a line.

For the parts you choose not to read line by line, the tests are the reader. This tutorial explains what each test does and how to read and extend it.

21.1 Why tests replace reading

Read

Help > Design > Subsystems > Tests and checks.

What happens

A black box is acceptable only with a written contract and tests that check exactly that contract. Then a change that breaks it fails a test, even if nobody reads the code.

Watch it

None.

Try

Pick one black-box part (the library index) and write its contract in five sentences, then find the tests for each.

21.2 test:tabs

Read

tests/tabSwitch.mjs.

What happens

A Playwright script drives the real app in a browser: it clicks tabs, opens items, drags handles, inserts layers, welds, prints, sweeps, steps and much more, collecting problems and failing on any page error or console error. It runs in stages named by stage = "...", so a failure says where.

Watch it

Terminal: npm run test:tabs (about eight minutes).

Try

Read one stage and change an expected value to see a failure message.

21.3 test:regression

Read

tests/regression.mjs; tests/regression/approved.json and approved/.

What happens

Every Draw object, pattern and gallery script is drawn and compared with its approved copy: the lines' geometry exactly (a fingerprint of every line's ends), or the picture within an allowance. Changes are listed with a report (approved, now, overlay, flicker, difference). An intended change is approved with -- accept <name>; an item may get its own allowance in tolerance.json.

Watch it

Terminal: npm run test:regression.

Try

Change one line colour in a copy of an object, run it, and read the report.

21.4 The Node tests

Read

tests/shapersConnectors.mjs, tests/controlConventions.mjs, tests/intersections.mjs.

What happens

Pure functions are tested in Node without a browser: shapers, connectors and curves (27), controls by name (6), the intersection search (11, including agreement with an every-pair search and a timing check).

Watch it

Terminal: npm run test:shapers, npm run test:controls, npm run test:intersections.

Try

Add a test for a shaper of your choosing.

21.5 test:errors, test:node, test:history, test:ideabook

Read

tests/errorReport.mjs, tests/nodeSmoke.mjs, tests/scriptHistory.mjs, tests/ideabook.mjs.

What happens

The error bar, log, checklist, Home subtabs and time limit; the Node service's requests on a scratch copy of the folders; Script history; every Ideabook hint script.

Watch it

Run each.

Try

Read the scratch-copy setup at the top of tests/nodeSmoke.mjs.

21.6 Lint and the import and id checks

Read

eslint.config.mjs; tests/importCheck.mjs; tests/idCheck.mjs.

What happens

Lint (npm run lint:globals) reports undeclared globals: zero errors is required (a few warnings in gallery scripts are known). The import check confirms every import resolves; the id check confirms the region table matches index.html.

Watch it

Run all three.

Try

Use an undeclared variable in a copy of a file and read the lint error.
