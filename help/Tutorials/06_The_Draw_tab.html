Written 6 November 2026 for Sketchpad on branch claude/tier-a. Files and functions are named rather than given line numbers, so the text stays right as lines move: in VS Code press Ctrl+P to open a file and Ctrl+Shift+O to jump to a function, or look it up in docs/FUNCTIONS.md. "Watch it" lines use the browser's developer tools (F12): Sources to set a breakpoint, Console to run a line.

The Draw tab shows one registry object at a time, each in its own subtab, with its controls. This tutorial goes through the tab's state and subtabs, the redraw, the caption menu, saved settings, Sweep and stepping.

6.1 Tab state and subtabs

Read

ui/draw/draw.js (initDrawTab, restoreDrawTab, saveDrawState), ui/draw/drawNav.js (setDrawSubtabs, addDrawSubtab, switchTab, deleteTab, markTabDirty, markTabClean), ui/draw/drawTabState.js.

What happens

Each open object has an entry in uiState.draw.tabs, keyed by subtab id ("tab-cycloid"), holding its registry object, its parameters and flags. The subtab bar has Categories, then one subtab per open object with an x to close it. Opening an object that is already open switches to it. A subtab is marked changed when a setting moves (markTabDirty).

6.2 drawActiveTab, line by line

Read

ui/draw/drawRunner.js (drawActiveTab).

What happens

It finds the active subtab's info, puts the shared canvas into #sketchpad, clears it, keeps the overlay layers in step, sets the redraw and change handlers, builds the controls, then calls update(params) and draw() inside the stepping pass and the time-limit clock, and draws the scaffold guides. Any error is caught here and reported (a choke point).

6.4 Saved settings (secondary objects)

Read

ui/draw/secondaryObjects.js; ui/draw/drawNav.js (showSecondaryOffcanvas, loadSecondaryObjectInTab, validateOpenSecondaryTabs); node/secondaryRequests.mjs.

What happens

An object's settings can be saved as a named .json under drawRegistry/<object>/. They are listed from the folder, opened as a copy of the object with those settings, saved again, or archived. The Draw category frame marks objects that have any.

6.5 Sweep

Read

ui/draw/drawSweep.js (sweepableSettings, sweepValues, sweepPictures, sweepGrid, parseValueList, openSweepPanel).

What happens

Sweep draws the object once per value of a setting into small pictures. Each picture uses a private copy of the object (makeDrawInstance), draws on the shared canvas, and is copied down. A second setting gives a grid; a typed list replaces From and To. Clicking a picture gives the object those values. The open object is redrawn afterwards, so the canvas ends as it began.

6.6 Stepping

Read

ui/draw/drawStep.js (startStepping, beginStepPass, endStepPass, stepLayer, showLine, updateReadout), and the stepping part of drawLine.

What happens

Stepping sets drawState.step. drawLine then counts every line, records it, draws only the first k and marks line k. Each redraw starts the count again (begin and end step passes), so dragging while stepping works. The controls sit in the left column as tab-extra; when they are removed by a tab switch, drawLine notices and stops stepping. In Figures the same code steps the whole figure or the active layer only.
