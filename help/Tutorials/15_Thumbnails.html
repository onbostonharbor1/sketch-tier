Written 6 November 2026 for Sketchpad on branch claude/tier-a. Files and functions are named rather than given line numbers, so the text stays right as lines move: in VS Code press Ctrl+P to open a file and Ctrl+Shift+O to jump to a function, or look it up in docs/FUNCTIONS.md. "Watch it" lines use the browser's developer tools (F12): Sources to set a breakpoint, Console to run a line.

The pictures in the category frames are files made by Sketchpad itself. This tutorial says where they live, how each kind is drawn, and how the tools regenerate and check them.

15.1 Where pictures live

Read

ui/thumbnailSettings.js (the path helpers); any library's images folder.

What happens

Each library keeps pictures beside its items, in an images folder, named thumb_<name>.png, 200 by 200 pixels: for example patterns/circles/images/thumb_circle.png, drawRegistry/rose/images/thumb_rose.png. They are committed with the code.

15.2 Making a picture

Read

ui/thumbnailMaker.js (listThumbnailTargets, renderTarget, prepareSharedCanvas, loadImage).

What happens

listThumbnailTargets lists what should have a picture, by set (Patterns, Gallery scripts, Gallery images, Draw, Figures). renderTarget draws each: a script is run on the canvas, a Draw object drawn with its defaults, a figure drawn, an image loaded and scaled; the canvas is copied down to 200 by 200.

15.3 Regenerate and Check Missing Images

Read

regenerateThumbnails, findMissingThumbnails in ui/thumbnailMaker.js; utilities/Tools/Thumbnails.

What happens

Regenerate makes every picture of the chosen sets and reports how many were made, skipped and failed (five animated scripts are skipped; voronoi fails to load). Check Missing Images lists items with no picture file.

Watch it

Run Check Missing Images.

Try

Delete one picture and run it again.

15.4 Writing a picture

Read

node/thumbnailRequests.mjs (writeThumbnail).

What happens

The page sends the picture as base64 with its kind, area, category and name; the service checks the names, builds the images folder path and writes the file.
