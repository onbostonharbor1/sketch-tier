11.1 The shared subtab builder

Read

ui/resultsViewController.js (buildSubtabBar, buildSubtabButton, activateSubtab).

What happens

A tab describes its subtabs with an adapter: a CSS class, a function giving the active id, and a list of tabs, each with an id, a label, an onClick and an optional condition (Results appears only when an item is open). buildSubtabBar builds the row from that; activateSubtab marks one active.

11.2 Each tab's subtab bar

Read

ui/home/homeNav.js, ui/draw/drawNav.js (setDrawSubtabs), ui/patterns/patternsNav.js, ui/gallery/galleryNav.js, ui/figures/figuresNav.js, ui/utilities/utilitiesNav.js.

What happens

Gallery: Ideabook, Patterns, Scripts and Results. Figures: Categories plus a subtab per open figure. Utilities: Tools, Lab, Result. Draw and Figures build their own bars because their subtabs open and close.

11.3 The caption bar

Read

ui/caption.js (setCaptionBar).

What happens

The caption shows the item's title, Prev and Next when a list can be stepped, the v button for the caption menu, and any extra buttons (the Ideabook's Run script). Each tab calls setCaptionBar with what it wants.

11.4 The caption menu

Read

ui/menuCmds.js (makeHelpItem, makeNotesItem, makeShowScriptItem, makeEditManifestItem, makeArchiveItem, makeScriptHistoryItem, makeThumbnailItem), and each tab's get...CaptionMenuItems.

What happens

Each tab builds a list of items: label, disabled, tooltip, onClick. Common items come from menuCmds.js so they behave the same everywhere (Help, Notes, Show Script, Edit Manifest, Archive, Script history, thumbnail). The Figures menu is the longest and is built fresh each time, so items grey out correctly (no figure, points mode, no active layer).

11.7 The side panel

Read

ui/offcanvas.js (showOffcanvas, showPanel, hideOffcanvas, onEscape).

What happens

One permanent panel slides in from the right with a title and a body, over a dimmed backdrop. It closes on its X, a click on the backdrop, or Escape. Sweep, Script history, Insert by picture and the Maintenance panels use it.

Watch it

11.8 Overlays

Read

ui/overlay.js (overlayManager, initOverlay, showHelpOverlay, showNotesOverlay).

What happens

The overlay container holds three panels: help (the Help browser and editor), forms (dialogs such as Edit Manifest) and debug. overlayManager shows one, hides one, or clears all; the close button clears all and resets the panel's size. Showing an overlay disarms the interactor so a drag cannot happen underneath.

Watch it

Open Help, then Edit Manifest; close each.

Try

Find where the interactor is disarmed when an overlay shows.

11.9 The Prev and Next overlay

Read

ui/nextPrevOverlay.js (enableNextPrevOverlay, disableNextPrevOverlay, disableAllNextPrevOverlays).

What happens

Some views put Prev and Next arrows over the canvas. They are turned off at the start of every tab switch, so a tab never inherits another's arrows.
