19.1 uiState, field by field

Read

ui/uiState.js.

What happens

activeTab. launch: the request from one tab to another (pending, sourceTab, targetTab, sourceType, registryKey, figurePath). homeAlert: what the alert bar has dismissed. Per tab: home (needsUpdate, showAllErrors, showAllChecks, saved view and item), draw (needsUpdate, activeSubtab, tabs), patterns, gallery, utilities, and figures (activeSubtab, tabs each holding a figure and its instances, hitRadius, snap radius, printUnits). thumbnails (on, size). instrument (on, entries).

19.2 drawState, field by field

Read

draw/drawState.js, the drawState object and DRAW_STATE_START.

What happens

title, canvasWidth, canvasHeight, debug; final (Final mode: points only); pts and ctr (old numbered points and their counter); transform and bounds (set per figure layer); collect (stitch ends while a figure layer draws); step (stepping); timeLimit, deadline, clockWhat, clockCalls (the time limit). resetDrawStateForScript puts it back to its start values (keeping the canvas size) before each script.

Console: the drawState during stepping, and during a figure layer's draw (breakpoint in redrawFigure).

19.3 What is kept where

Read

ui/thumbnailSettings.js (localStorage), ui/patterns/patterns.js (sessionStorage), the libraries (files).

What happens

In memory only: uiState and drawState, so a reload starts every tab fresh. In the browser's local storage: the thumbnail settings. In session storage: Patterns' remembered view. In files: figures, saved settings, scripts, help, notes, the checklist, logs and pictures.

Watch it

Application panel (F12): Local Storage and Session Storage.

Try

Reload and list what survived.

19.4 Written through immediately

Read

CLAUDE.md (Design rules); any control's applyValue; any tab's saved-state writes.

What happens

A change is written where it lives the moment it is made: a slider writes the object's params, opening an item writes the tab's saved state. So a tab switch has nothing to save, and setUI never calls save(). It is why tab switching is simple and why nothing is lost by switching.

Watch it

Move a slider, switch tab and back: the value is there, with no save step anywhere.

Try

Find a place where state is copied instead of written through, if any, and think about whether it matters.
