Tutorial 20: End-to-end traces

Written 6 November 2026 for Sketchpad on branch claude/tier-a. Files and functions are named rather than given line numbers, so the text stays right as lines move: in VS Code press Ctrl+P to open a file and Ctrl+Shift+O to jump to a function, or look it up in docs/FUNCTIONS.md. "Watch it" lines use the browser's developer tools (F12): Sources to set a breakpoint, Console to run a line.

These traces follow one action from the click to the screen through every file it touches. They are the capstone: each one ties several earlier tutorials together. For each, set the breakpoints named, perform the action, and write down the call stack at each stop.

20.1 Opening the app

Read

main.js, ui/errorReport.js, draw/drawState.js, drawRegistry/drawRegistry.js, ui/registryCheck.js, ui/setUI.js, ui/home/home.js, ui/home/homeManifest.js, node/libraryIndex.mjs.

What happens

Imports run in order (1.3); the registry is checked; onDomContentLoaded starts menus, overlays and layers and wires the tabs; setUI(START_APP) applies the Home theme and starts Home with init(false); Home builds its subtabs and caption, shows the alert bar if needed, and asks for listHomeItems; the service reads the folders; Home groups by status and categories.js draws the frames.

Watch it

Breakpoints: onDomContentLoaded, initHomeTab, loadHomeManifest_async, renderCategories.

20.2 A Draw object: open, drag, slide

Read

ui/draw/drawCategories.js, drawNav.js (addDrawSubtab), drawRunner.js (drawActiveTab), the object's file, ui/interactor.js (moveHandle), ui/controls (a slider's applyValue), draw/drawUtilities.js (drawLine).

What happens

Clicking an item opens a subtab and calls drawActiveTab: controls built, update, draw (each line through drawLine), handles armed. Dragging a handle goes through moveHandle, update and redraw. Moving a slider writes the param and calls the redraw.

Watch it

Breakpoints: addDrawSubtab, drawActiveTab, moveHandle, a slider's applyValue.

Try

Note how many times drawLine runs for one slider move.

20.4 A gallery script, then its history

Read

ui/gallery/galleryResults.js (showGalleryScript), ui/scriptRunner.js, ui/scriptHistory.js, node/scriptHistoryRequests.mjs.

What happens

Clicking a script loads it fresh, resets drawState, runs runPattern inside the clock, arms handles and builds controls. Script history asks the service for VS Code's saved versions and shows them with Run and Compare.

Watch it

Breakpoints: showGalleryScript, executeScriptToCanvas, fillPanel.

Try

Run an older version and compare it with the current one.

20.5 An error, from where it happens to the ticked log line

Read

Any drawing code, the nearest choke point, ui/errorReport.js, node/logAndEditorRequests.mjs (appendErrorLog), ui/errorChecklist.js, ui/home/homeErrors.js.

What happens

An error is thrown in a drawing; it rises to the choke point, which calls reportError; the bar shows it; appendErrorLog writes the line; Tick writes Acknowledged; Home > Errors reads every log and leaves it out.

Watch it

Breakpoints: reportError, writeToLog, acknowledge, errorStates.

Try

Purge it and read the log.

20.6 A file saved in VS Code, until it appears on Home

Read

node/libraryIndex.mjs, ui/manifest.js, ui/home/homeManifest.js, Edit Manifest.

What happens

Save a new pattern; reload; it appears in Patterns (listLibrary). Give it a status with Edit Manifest; the manifest note is written; the complete rebuild runs; Home asks listHomeItems and shows it under that status.

Watch it

Breakpoints: loadOrCache, applyEditManifest, loadHomeManifest_async.
