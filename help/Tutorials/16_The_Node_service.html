Tutorial 16: The Node service

Written 6 November 2026 for Sketchpad on branch claude/tier-a. Files and functions are named rather than given line numbers, so the text stays right as lines move: in VS Code press Ctrl+P to open a file and Ctrl+Shift+O to jump to a function, or look it up in docs/FUNCTIONS.md. "Watch it" lines use the browser's developer tools (F12): Sources to set a breakpoint, Console to run a line.

Anything that reads or writes files goes through a small Node program on port 5174. The page reaches it through Vite. This tutorial goes from the server's front door to each family of requests, then the page side and Codespaces.

16.1 The server

Read

node/sketchpadServer.mjs (isRequestAllowed, statusForError, the request handling).

What happens

It listens on 127.0.0.1:5174, accepts POST /dispatch with a JSON body { requestName, payload }, and refuses a request whose Origin is not Sketchpad's page or whose Host is not its own (which blocks other web pages and DNS-rebinding tricks). Bodies are limited in size. A bad request answers 400 with its message; anything else that fails answers 500.

Watch it

Terminal: curl -s -X POST localhost:5174/dispatch -H 'Content-Type: application/json' -d '{"requestName":"listLogFiles","payload":{}}'.

Try

Send the same with -H 'Origin: https://example.com' and see it refused.

16.3 Path safety

Read

node/safePaths.mjs (isInside, manifestRoots, RequestError).

What happens

Every path built from request text is resolved and checked to lie inside its allowed folder, so a request cannot reach files elsewhere (no ../ escapes).

16.4 Atomic writes

Read

node/serviceFileHelpers.mjs (writeFileAtomicSync, writeJsonFileSync).

What happens

A file is written beside its target under a temporary name, then renamed over it. A rename is all or nothing, so a crash part way never leaves half a file.

16.6 The page side

Read

ui/nodeLayer.js (nodeDispatch and the helpers).

What happens

nodeDispatch(name, payload) posts to /dispatch on the page's own server and returns the JSON. If nothing answers, or Vite answers for a missing service, it throws a plain message: "The Node service did not answer ... start it with npm run dev:all".

16.7 Vite's role

Read

vite.config.js.

What happens

Vite serves the page and passes /dispatch to the service. It marks a request from Sketchpad's own page, whatever address the page was reached at, as coming from localhost:5173, so the service accepts it; a request from another site keeps its own origin and is refused. allowedHosts lets the page be reached at a Codespace's address.

16.8 Codespaces

Read

.devcontainer/devcontainer.json; Help > Design > Subsystems > Running in a Codespace.

What happens

A Codespace installs the packages once and starts Vite and the service each time it opens; port 5173 is forwarded. Work done there must be committed and pushed. Open in VS Code opens the Codespace's browser editor; Script history shows the Codespace's own versions.
