Written 6 November 2026 for Sketchpad on branch claude/tier-a. Files and functions are named rather than given line numbers, so the text stays right as lines move: in VS Code press Ctrl+P to open a file and Ctrl+Shift+O to jump to a function, or look it up in docs/FUNCTIONS.md. A Draw object is one file in drawRegistry/ that knows its settings, its controls and how to draw itself. This tutorial takes an object apart, walks through simple, stitched, node-ring and curve-library objects, and then goes through making a new one, naming it, and the checks it must pass.

3.1 Anatomy of a registry object

Read

drawRegistry/drawLine.js (short and complete). Then ui/registryCheck.js (checkRegistryEntry) for the fields every object must have.

What happens

An object is a plain JavaScript object put on window as drawRegistry_<name>. Its parts: name (shown in menus), id (its registry key, permanent), version, category, handleNames (what each handle is), params (its settings, including points, the handle positions), controls (the sliders and pickers for its params), and four functions. init() builds its working pieces (elements) from params; update(incoming) brings them in line after a change; draw() draws, only through drawLine; infrastructure(), optional, lists the lines that can carry discs in Figures.

The registry object is a single shared copy. Figures and Sweep make private copies with Object.create(entry) and their own structuredClone(entry.params), then call init(); that is how two layers of the same object have different settings.

Watch it

Console: Object.keys(window.drawRegistry) and window.drawRegistry.parabola.params.

Try

For drawLine.js, write down the order init, update and draw run in when you drag the midpoint handle, then check with breakpoints.

3.2 A simple one: Line

Read

drawRegistry/drawLine.js, all of it.

What happens

Line has three handles: the two ends and the midpoint. init() fills params.points if empty and builds a Line and a StringThing. update() looks at whether the midpoint handle moved: if it did, the whole line moves (moveMidpointTo); otherwise the ends were dragged and the line takes them. Then the params and handles are written back from the Line so they agree. infrastructure() says the line is one arm with its two end points, so in Figures a disc can sit on either end.

Watch it

Sources: breakpoint in Line's update; drag the midpoint, then an end, and see which branch runs.

Try

Change infrastructure() in a copy so the line offers 10 points along its length (steps: 10, to: 10) and try Points Mode in Figures.

3.3 A stitched one: Parabola, then Inverse Star

Read

drawRegistry/parabola.js; drawRegistry/inverseStar.js with draw/drawRegular.js (drawInverseStar, createArms, createParabs).

What happens

Parabola has four handles (two arms, each with a start and an end) and a step count; it stitches arm 1 to arm 2 point for point. Inverse Star builds a ring of nodes, makes spokes from the centre and sides between nodes, turns each into an arm of points, and stitches each spoke to a side, so the curves bow outward. Both show the older pattern: params feed a StringThing, and a draw function in draw/ does the work.

Watch it

Sources: breakpoint in drawInverseStar; move the Nodes slider; step into createArms.

Try

Find Truncate and Shorten in Inverse Star's controls and work out from changeLine what each removes.

3.4 Node-ring objects: Mystic Rose and Cycloid

Read

drawRegistry/mysticRose.js, drawRegistry/cycloid.js; draw/drawUnicorns.js (drawMysticRose, drawCycloid).

What happens

These start from one ring of nodes. Mystic Rose joins every node to every other; Cycloid joins node i to node (i x loops) mod n, the times-table rule. Their only handle is the centre. Their infrastructure() returns the node ring as one arm, so in Figures every node can carry a disc.

Watch it

Console: window.drawRegistry.cycloid.infrastructure and read it; then in Figures insert a Cycloid and tick Points Mode.

Try

Predict how many lines Mystic Rose draws with 20 nodes (n(n-1)/2), then count them with stepping.

3.5 The ring-object maker: how Rose is built

Read

drawRegistry/rose.js (about twenty lines), draw/ringObject.js (makeRingObject), draw/curves.js (rosePoints).

What happens

The twelve curve and shape objects are all the same kind of object, so one maker builds them. rose.js says only what is Rose's own: name, id, category, the points function, and its extra setting (Petals). makeRingObject adds everything else: the centre and size handles, Points, Stitch, Skip, Factor, colour and line width; update() keeps the size handle and the Size slider in step (whichever changed last wins); draw() gets the points and joins them by the stitch setting with a connector; infrastructure() offers the points for discs.

Watch it

Sources: breakpoint in the maker's update; drag Rose's size handle, then move the Size slider.

Try

Make a thirteenth curve in a copy: a points function in curves.js and a file like rose.js, then register it (3.8).

3.6 Interesting ones: Circular Parabola (Multi) and Linked Circles

Read

drawRegistry/circularParabolaMulti.js; drawRegistry/linkedCircles.js with draw/drawLinkedCircles.js (buildCirclePairs).

What happens

These exist because they are good to play with. Circular Parabola (Multi)'s second handle separates and joins four copies. Linked Circles draws several circles and links them by a style: pairwise (each to the next), ring (and the last back to the first) or all to all; that is what makes tubes and rings from a few circles. Linked Circles is the one object the registry check flags: it strokes its circles itself rather than through drawLine (known, left as is).

Watch it

Open each in Draw and drag the handles slowly.

Try

Read buildCirclePairs and predict the pairs for 5 circles in each style.

3.7 Parametrics as a registry object

Read

drawRegistry/parametrics.js (buildCurveFromParams, setVariantAndRedraw, its handles), draw/drawParametrics.js.

What happens

Parametrics chooses among curve variants from a menu, then hands buildCurveFromParams the settings the drawing code needs. Its centre handle moves the curve and its size handle zooms it. Show Intersection Dots turns on the crossing search (2.9).

Watch it

Draw > Parametrics: choose two variants, tick the dots, drag the size handle.

Try

Find where the zoom from the size handle reaches autoFitParametricToCanvas.

3.8 Making a new object, start to finish

Read

Any two registry files; main.js (the registry imports); drawRegistry/drawRegistry.js; docs/registryNames.md.

What happens

Steps: write drawRegistry/<name>.js (or a points function plus a small file for a curve); import it in main.js; add it to the object in drawRegistry/drawRegistry.js under its permanent key; record the name in docs/registryNames.md if it could be confused with another; reload and check the red bar stays empty (the start-up check); open it in Draw; run npm run test:regression and approve it (-- accept <name>); make its thumbnail (Utilities > Tools > Thumbnails > Regenerate, Draw). The promotion rule: an idea grows in a gallery script first, reusable code moves into draw/, you minimise it, and only then does it become a registry file.

Watch it

None.

Try

Do it for a trivial object (a single circle of points with polyline), then delete it.

3.9 Registry names are permanent

Read

CLAUDE.md (Design rules), docs/registryNames.md.

What happens

Saved figures store each layer's object by its registry key. Renaming a key would break every figure that uses it. So names are chosen once, from the shape drawn, descriptively; an ambiguous one (polygon, ellipse, archimedeanSpiral) is explained in docs/registryNames.md. The menu name (name) can change freely; the key cannot.

Watch it

Open a saved figure .json in VS Code and find the id of each layer.

Try

Find the one old key whose name and menu name differ (drawLine and Line).

3.10 The registry check

Read

ui/registryCheck.js (checkRegistryEntry, checkDrawRegistry); Utilities > Tools > Validate Draw Registry.

What happens

At start-up every object is checked: name, an id equal to its key, a whole-number version, a category, true/false for firstOrder and interactive, elements, the four functions, params and controls, handleNames matching the handles after init, and every slider's default inside its range. Validate Draw Registry also draws each object to see it draws only through drawLine. A fault goes to the red bar, naming the object and the rule.

Watch it

Utilities > Tools > Validate Draw Registry.

Try

Give a copy of an object a slider default outside its range and read the message.
