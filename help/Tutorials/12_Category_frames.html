Tutorial 12: Category frames

Written 6 November 2026 for Sketchpad on branch claude/tier-a. Files and functions are named rather than given line numbers, so the text stays right as lines move: in VS Code press Ctrl+P to open a file and Ctrl+Shift+O to jump to a function, or look it up in docs/FUNCTIONS.md. "Watch it" lines use the browser's developer tools (F12): Sources to set a breakpoint, Console to run a line.

The frames of pictures or names you click to open items are drawn by one file, ui/categories.js, which knows nothing about tabs or lists. Each tab hands it a description.

12.1 The descriptor

Read

The header of ui/categories.js; buildCategoryDescriptor.

What happens

A descriptor is a list of frames, each with a title and items; an item has a name, an onClick, and optionally a picture path (thumb) and a has-subitems flag. Every decision (what the frames are, what a click does) is made by the tab before it calls categories.js.

Watch it

Breakpoint in renderCategories; open Patterns; look at the descriptor argument.

Try

Write a two-frame descriptor in the console and render it into #text.

12.2 renderCategories, line by line

Read

renderCategories, buildCategoryFrameElement, buildCategoryItemElement, setActiveItem, clearCategoryFrame.

What happens

For each frame it builds a titled box; for each item an element showing the picture or the name, with the name as hover text and the click handler attached; setActiveItem marks the one chosen. It fails at once, with a clear message, if the descriptor is malformed.

Watch it

Elements panel on a frame.

Try

Pass an item without onClick and read the message.

12.3 Pictures in frames

Read

ui/thumbnailSettings.js (thumbFromEntryPath, patternsThumb, galleryThumb, figureThumb, drawThumb, setThumbnailsOn, setThumbnailSize).

What happens

When pictures are on, an item with a thumb shows its picture at the chosen size, falling back to its name if the file is missing. Each library keeps pictures as images/thumb_<name>.png beside its items; the helpers build those paths.

Watch it

Utilities > Tools > Thumbnails: toggle pictures and change the size.

Try

Rename one thumbnail file and see the name appear in its place.

12.4 Each tab's frames

Read

ui/draw/drawCategories.js (renderDrawCategories), ui/patterns/patternsNav.js (showCategoryList), ui/gallery/galleryNav.js (showIdeabookCategories, showPatternsCategories, showScriptsCategories), ui/utilities/utilitiesDisplay.js (setUtilityCategories), ui/figures/figuresDisplay.js, ui/home/homeNav.js (buildHomeCategoryDescriptor).

What happens

Draw's frames come from the registry's categories (curves and shapes among them), marking objects with saved settings. Patterns, Gallery, Utilities and Figures come from the library lists (tutorial 13). Home's come from statuses.

Open each tab's categories.

12.5 The isolation rule

Read

The header of ui/categories.js.

What happens

categories.js must not know about tabs, manifests or lists. Keeping it ignorant is what lets one file draw every tab's frames, and lets the lists change (as they did in November) without touching it.

Watch it

None.

Try

Search categories.js for uiState: what is the only thing it reads, and why is that acceptable?
