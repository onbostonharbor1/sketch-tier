A figure is several Draw objects (layers) arranged together, with discs that become nails, welds that join points, and print aids that make the template. It is the largest part of Sketchpad and the part most worth knowing well. Read the tutorials in order: each builds on the one before.

7.1 The figure data model

Read

ui/figures/figureModel.js (createEmptyFigure, newLayerFields, upgradeFigureV1, snapshotOfFigure, hasUnsavedChanges, checkFigureFormat); docs/FIGURE_FORMAT_V1.md.

What happens

A figure is plain data in uiState.figures.tabs[tabId].figure: name and category; layers (each with its registry id, a permanent lid such as L1, objectVersion, role, includeInOutput, visible, params and transform); points (the discs, each with a number n that is never reused, a layer, and either a position or an anchor on an arm); welds; drawOrder (layer indexes, top first); activeLayer; nextPoint; and the print settings units, scale and nail. Layer numbers never change: a deleted layer stays as a marked entry. The working objects that draw each layer live beside it in instances, rebuilt from the data. snapshotOfFigure and hasUnsavedChanges compare against the last save; checkFigureFormat lists any problems when a file is opened.

Watch it

Console on a figure: uiState.figures.tabs[uiState.figures.activeSubtab].figure.

Try

Save a small figure and read its .json beside docs/FIGURE_FORMAT_V1.md, field by field.

7.2 Inserting layers

Read

ui/figures/figureLayers.js (insertLayer, offsetParams, listInsertableObjects, wireInstance, rebuildInstances); ui/figures/figuresNav.js (addCaptionTools); ui/figures/figureInsertPanel.js (openInsertPanel).

What happens

Layers come from the caption buttons (Line, Parabola, Rectangle, Polygon, Ellipse), the Curve list, the Insert Object list and the Insert... picture panel. insertLayer(tabId, key) makes a private copy of the registry object, shifts its handles a little so a second copy does not sit exactly on the first (offsetParams), adds the layer data, puts it at the top of drawOrder, makes it active and redraws. wireInstance connects the copy's controls and handles to the figure.

Watch it

Breakpoint in insertLayer; press Rectangle.

Try

Insert the same object twice and compare their params: what did offsetParams change?

7.3 Drawing a figure

Read

ui/figures/figureDraw.js (redrawFigure).

What happens

redrawFigure clears the canvas, then draws the layers bottom to top in paint order: drawOrder, with the active layer lifted to the top while it is chosen. Each layer gets its transform, bounds and stitch-end collector set in drawState, is dimmed if it is not active, runs update() and draw() inside the time-limit clock and the stepping pass, and is caught on its own if it fails, so the other layers still draw. Roles decide what shows: guides (templates) are left out of Show All and Final; scaffold is shown while working and in Show All but never in Final or print. After the layers come the discs, the magic-point marks, the spacing marks, the weld marks and the centroid.

Watch it

Breakpoint at the top of the layer loop; watch drawState.transform change per layer.

Try

Make a layer scaffold (caption menu) and see where it disappears: Final, print, Show All.

7.4 Layer transforms: move and rotate

Read

draw/drawTransform.js; ui/figures/figureCentroid.js (drawCentroid, centroidHit, activateCentroid, geometry).

What happens

Each layer's transform is an angle and an offset. Dragging the centroid changes the offset (translateTransform); selecting it shows the bounding box, whose handle rotates the layer about its centre (rotateTransformAbout). The object itself never changes; drawLine maps its lines, and handles and discs are mapped the same way.

Watch it

Console: the active layer's transform before and after a rotation.

Try

Rotate a layer 90 degrees, save, reopen: where is the angle stored?

7.5 Points mode: discs

Read

ui/figures/figurePoints.js (findCandidate, addAnchoredPoint, addFreePoint, moveFreePoint, deletePoint, refreshPoints, drawFigurePoints, armsOf, armPoint); ui/figures/figurePointer.js.

What happens

In points mode a click on the active layer either selects a disc, places a disc anchored on one of the layer's arms (from the object's infrastructure()), or places a free disc. An anchored disc remembers its arm and how far along it is (t), so it rides along when the object changes; refreshPoints recomputes every anchored disc's position before drawing. Disc numbers are never reused. Free discs can be dragged; anchored ones cannot.

Watch it

Breakpoint in findCandidate; click near a line in points mode.

Try

Put a disc half way along a Parabola arm, change the step count, and explain why it stays put.

7.6 Magic points

Read

ui/figures/figureMagic.js (magicCandidates, findFeature, curveFeatures, crossings, drawMagicMarks).

What happens

Beyond the evenly spaced points, some places are worth a disc: the middle of a straight arm, a lobe tip, a cusp, and a crossing with another arm. Each has a name ("mid arm1", "tip ring #3", "cross L2.arm1 #1"), so a disc placed on one finds it again after the shape changes (findFeature). Crossings use the fast search of tutorial 2.9; they are drawn as purple rings with a cross, the others as open diamonds.

Watch it

Breakpoint in crossings; tick Points Mode on two crossing lines.

Try

Place a disc on a crossing, move one line, and watch the disc follow.

7.7 Welds

Read

ui/figures/figureWelds.js (weldHandleDrop, toggleWeldAt, discOnHandle, cornerPartners), figureWeldModel.js (createOrJoinWeld, removeFromWeld, weldOf), figureWeldMove.js (propagateAfterChange, applyFollowerMove, translateWholeLayer), figureWeldMarks.js.

What happens

A weld is a group of discs that should stay together: figure.welds is a list of groups, members named by disc number. Dropping a handle on another layer's handle snaps them and welds them (weldHandleDrop). When a welded point moves, the other members follow (propagateAfterChange): their handles are moved, or a whole layer is moved when the weld calls for it. Whether a group still meets is not stored; the marks are worked out on each draw, black when they meet and red when not. If a layer's point count changes, the weld is not changed: you fix it by hand.

Watch it

Breakpoint in propagateAfterChange; drag a welded handle.

Try

Weld three parabolas at one corner, then drag the corner: trace which members move and why.

7.8 Break apart

Read

ui/figures/figureBreakApart.js (canBreakApart, breakApartLayer).

What happens

A composite object, such as a polygon of stitched parabolas or Inverse Star, can be replaced by its pieces: separate layers (lines and parabolas) that each can be edited, welded where they met.

7.9 Templates as guide layers

Read

ui/figures/figureTemplates.js (registerTemplates, insertTemplate, TEMPLATE_CHOICES).

What happens

The Template... list inserts a guide: a shape drawn grey to draw against, never printed and left out of Show All. Templates are registry objects marked as templates, added to the registry only for Figures.

7.10 Print aids

Read

ui/figures/figurePrint.js (nailsOf, spacingProblems, setPrintSize, setNailSize, templatePages, printTemplate, oneSheetSVG, saveOneSheetSVG, toUnits, fromUnits).

What happens

nailsOf turns the figure into nails: every disc on a layer that prints, a weld group as one nail, unwelded discs on one spot as one nail, or the stitch ends if there are no discs. Scale is millimetres per canvas pixel, set by Print size from the width you want (asked in inches unless switched). The spacing check rings pairs closer than nail diameter plus clearance; it never stops printing. Print template makes sheets of true-size SVG with a cover page, calibration line and alignment marks; the one-sheet SVG is the whole template in one file, nails optionally coloured red, green, orange, blue, yellow in turn.

Watch it

Console: (await import('/ui/figures/figurePrint.js')).nailsOf(uiState.figures.tabs[uiState.figures.activeSubtab]).nails.length.

Try

Weld two discs and confirm the nail count drops by one.

7.11 Saving and opening

Read

ui/figures/figuresSave.js (saveFigureAs, saveFigureTab, sendSave, openSavedFigure, copyFigureTab, resetFigureTab, archiveFigureTab, writeFigureThumbnail); node/figureFiles.mjs (saveFigure).

What happens

Save As asks for a name and category, and the Node service writes figures/<category>/<name>.json atomically (written beside, then renamed). A picture is written for the category list. Opening reads the file, checks it (checkFigureFormat), upgrades an older format, and rebuilds the layers' instances. Closing an unsaved figure asks first. Copy, Reset and Archive are in the caption menu.

Watch it

Breakpoint in sendSave; Save As.

Try

Open a saved figure, change it, close it: find the code that asks before losing changes.

7.12 Stepping in Figures

Read

ui/figures/figuresCommands.js (the Step through the drawing item), ui/draw/drawStep.js (stepLayer), ui/figures/figureDraw.js.

What happens

The same stepping as Draw: the figure redraw calls the step passes and stepLayer(i) before each layer. The whole figure is stepped bottom layer first, or, with Active layer only, just the active layer while the others draw in full. The readout names the layer.

Watch it

Step a two-layer figure and watch the layer number change in the readout.

Try

Use Active layer only to find a fault in one layer of a busy figure.
