Figure file format, Version 1 (format 1)

A saved figure is figures/<category>/<name>.json. It is the figure object from ui/figures/figureModel.js, written as JSON. This file is the reference for what each field means, and for the rules that let Version 2 import every Version 1 figure.

The rule that protects old files

From 1 November 2026 the format may only gain fields. Nothing is renamed, removed or given a new meaning. A new field gets a default in upgradeFigureV1() (so older files open the same as new ones) and a check in checkFigureFormat(). Save refuses to write a figure that fails the check, so every file on disk is well formed.

Layer

FieldMeaning
kind"draw"
idThe draw registry key ("parabola", "drawLine" ...). Registry keys are permanent.
lidThe layer's permanent name: "L1" for the first layer, "L2" for the second, and so on.
objectVersionThe registry object's version when the layer was inserted (a whole number).
role"stitch", "guide", "scaffold" or "image". Guides and scaffold never print.
includeInOutputWhether the layer prints. Separate from visible.
visibleShown while editing. Hidden layers still appear in Show All.
deletedOptional, true for a deleted layer. The entry stays so numbers never change.
colorThe layer's identity colour (its number chip and discs), not its drawing colour.
paramsThe object's settings, as the registry object keeps them. Includes points, the object's own copy of its handle positions, which mirrors named fields such as pt1. Readers should prefer the named fields.
transform{ angle, tx, ty }: the layer moved and turned as a whole.

A layer's index in layers is permanent (layers are never removed), so points and welds refer to layers by index. lid is always "L" plus the index plus one.

x, y is where the disc was drawn on the canvas when saved; dx, dy is a label offset. Both are recomputed on open.

Handle names

Each registry object with handles declares handleNames: a list (one name per entry of params.points) or, for Linked Circles, a prefix ("circle": circle1, circle2 ...).

How Version 2 imports a format 1 figure

  • Each layer becomes a layer with the same lid, role, transform and output setting. Its generator is chosen by id, and its settings pass through that generator's "from Version 1" mapping, keyed by objectVersion.
  • Each weld group whose members are free or handle discs becomes one shared point. A group containing an anchored disc becomes an attachment to that disc's arm at t.
  • Discs that are not welded become point-table entries: free ones by position, anchored ones as attachments. An anchored disc with a feature becomes an attachment by feature (V2's finders use the same names).
  • scale carries across, so a figure calibrated for printing in Version 1 stays calibrated.

Saved Draw settings

A saved Draw variation (Draw > caption menu > Save as secondary) carries id, version, format: 1, createdBy: "sketchpad-v1" and params, so Version 2 imports it through the same mapping.
