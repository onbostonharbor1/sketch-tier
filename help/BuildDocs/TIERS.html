3. Order of work

Progress: step 1 built (3 Nov 2026): draw/shapers.js, draw/connectors.js, drawPairs, npm run test:shapers (20 tests). The Ideabook routines are not yet rewired to use them; that is for Barry to choose (promotion rule). Step 2 built (3 Nov 2026): Draw caption menu > Step through the drawing (ui/draw/drawStep.js). drawLine counts and records every line while drawState.step is set, draws the first k and marks line k in red; controls in the left column (first, previous, next, last, slider, readout of the line's ends and colour, Done). Works on every Draw object unchanged. Figures and scripts: not yet (the same drawLine hook serves them; their controls come later). Step 3 built (3 Nov 2026): errors as a checklist (ui/errorChecklist.js): Tick and Tick all in the error bar write "Acknowledged: ..." to the error log; Home > Errors lists every error not yet ticked, from all error logs, across restarts; Home's alert counts unticked errors. Home > Notes shows home/notes.md, opened in VS Code from there.

Each step is a phase on its own branch, reviewed and merged by Barry, in this order:

  1. A1, A2, A9, A10: the shapers and connectors library (draw/shapers.js, draw/connectors.js), pulled from the Ideabook routines and the stitcher, with tests.
  2. A3: the stepping view.
  3. A25, A26 (Errors and Notes): the error checklist and the first Home subtabs.
  4. A24, then A26 (Workbench): the library index, the migration, and the Workbench.
  5. A19 to A23: output.
  6. A12: undo.
  7. A11, A13 to A15: welds as groups, and the visualization pass.
  8. A30 to A34: the commands table, settings, conventions, groups, and Sweep over two settings.
  9. A4 to A8, A16, A18, A27 to A29, A35, A36: the rest, in any order Barry likes.

4. What else is needed before or during the work

  • Phases, not one batch. Thirty-eight items is about nine phases. Several touch every tab (A30, A24), so each phase is reviewed before the next is built on it.
  • Barry's decisions, wanted when a phase reaches them, not now:
  • A11: whether a weld row stores one value (members read it) or copies (members kept equal). Both are described in Oceania's docs/reviews/owner-comments-revC.md.
  • A16: what a template holds beyond guide layers.
  • A22: what an alignment mark looks like.
  • A31: which values appear on the settings page first.
  • A12 (undo) needs every figure change to go through a few known functions, so a snapshot can be taken before each one. In V1 that means finding every place that changes a figure. Most of these already sit in figureLayers.js, figureWelds.js and figureCentroid.js. Expect that phase to tidy those paths. It's real work, not a bolt-on.
  • A24 needs Windows testing on Barry's PC: Node's file watching misbehaves on Windows and in OneDrive-synced folders.
