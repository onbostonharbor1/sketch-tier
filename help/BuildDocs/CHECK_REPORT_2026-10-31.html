Fixed during the check

  • test:node touched the real repo and failed on a fresh clone. maintain_manifests.mjs now honors SKETCHPAD_ROOT; the test sets it to its scratch copy and waits for the rebuild to finish (commit 3b1ff9c).

Found and left alone

  • voronoi.js needs an internet connection (CDN import of d3-delaunay), so T14 ("works with Wi-Fi off") does not hold for that one script.
  • window.interactor and window.CanvasManager guards are dead (pre-existing).
  • 68 exported names that no other file mentions (most pre-existing, e.g. getDrawCaptionMenuItems, saveHomeState); candidates for a later dead-code pass.
  • A fresh checkout has no utilities/logfiles folder until the first manifest rebuild creates one; Utilities > Show Logs before that point reports "log dir missing".
  • The baseline checkout does not run from a clean npm install (its lock file was out of date and jquery, jstree and tinymce were not in its package.json); the sweep's first commit fixed that.
