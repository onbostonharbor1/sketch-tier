Stepping through a drawing

Written 5 November 2026. Code: ui/draw/drawStep.js, and a few lines in drawLine (draw/drawUtilities.js) and drawActiveTab (ui/draw/drawRunner.js).

Barry found drawing errors by stepping through a drawing in the debugger and watching the lines go down one at a time. Draw > caption menu > Step through the drawing does the same on the canvas.

How it works

drawLine is the one door every registry line goes through. While drawState.step is set ({ limit, count, lines, box }), drawLine counts every line it is asked for, records it in lines, draws only the first limit, and draws line number limit thick and red with a dot at its start. So any Draw object can be stepped without changing it.

Each redraw starts the count again: drawActiveTab calls beginStepPass() before the object draws and endStepPass() after, which updates the slider and the readout. Moving a slider or dragging a handle while stepping shows the first k lines of the changed drawing.

The controls

In the left column (#button, class tab-extra): first, previous, next, last, a slider, the readout "Line k of N: (x, y) to (x, y), colour", and Done stepping. A tab switch removes the controls; the next drawLine sees they are gone and stops stepping.

Not yet

Figures and scripts: the same drawLine hook serves them; they need their own controls. Stepping in Figures is on the list before the next tier.
