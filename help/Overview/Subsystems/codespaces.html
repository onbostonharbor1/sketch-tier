Running in a Codespace

Written 5 November 2026. Code: vite.config.js, .devcontainer/devcontainer.json, nodeDispatch in ui/nodeLayer.js.

Sketchpad can run in a GitHub Codespace, which is how Barry can use it from the iPad.

What made it possible

The page used to send every service request to http://localhost:5174/dispatch. On the iPad "localhost" is the iPad, and Safari blocks a plain-http request from an https page. Now the page posts to /dispatch on its own server, and Vite passes the request to the service on port 5174 (vite.config.js). The page never needs to know where the service is.

The service still refuses other sites. Vite marks a request that came from Sketchpad's own page, whatever address the page was reached at, as coming from http://localhost:5173; a request from any other site keeps its own origin and is refused (403). allowedHosts lets the page be reached at *.app.github.dev.

Using it

On github.com: the repository, the branch, Code > Codespaces > Create codespace. The .devcontainer runs npm install once and npm run dev:all each time the Codespace is opened, and forwards port 5173, where the app is. Commit and push work done there. Stop the Codespace when done (free hours are limited). Open in VS Code opens the Codespace's browser editor; Script history there shows the Codespace's own saved versions.
