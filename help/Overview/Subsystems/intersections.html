Intersections: a fast, tunable search

Written 6 November 2026. Code: draw/intersections.js. Used by Parametrics (draw/drawParametrics.js) and the crossing marks in Figures (ui/figures/figureMagic.js). Tests: npm run test:intersections.

findIntersections(paths, options) takes one or more paths (arrays of points, joined in order) and returns every place where a segment crosses another: a path with itself, or two paths with each other. It draws nothing.

Why it is fast

The old searches tested every new segment against every earlier one: n × n work, 200 million tests for a 20,000-point curve. The new one lays an invisible grid over the paths, notes each segment in the grid squares its box touches, and tests a segment only against those already in its squares. Crossing segments always share a square, so nothing is missed, and the answer is exactly the every-pair answer (the tests check this on random paths). A 20,000-point curve with over a thousand crossings takes about 35 ms.

The settings

OptionDefaultWhat it does
cellSizetwice the average segment lengthgrid square size in pixels
neighbourSkip1segments this close in order along one path are not tested (no mark at every joint)
endMargin0fraction of each segment end where a crossing does not count
countEndsfalsecount segments that only touch at an end
mergeDistance0.5 pxcrossings closer than this become one
mode"both""self", "between" or both
closedfalsea path's last point joins its first (true, or one per path)
maxCount2000stop after this many, with a note
timeLimit1000 msstop after this long, with a note, keeping what was found

What it returns

{ points, notes }. Each point is { x, y, a, b }; a and b name the two segments (path, segment number, and how far along, 0 to 1), so a disc on a crossing can find it again. notes says when a limit cut the search short.

Where it is used

  • Parametrics, Show intersections: the old rule is kept (segments up to 2 apart not tested, 1% at each segment end not counted), and an object or script may pass thing.intersections to change any setting. Any note is kept in thing.intersectionNotes.
  • Figures, crossing marks (points mode): each arm against each other arm, ends that touch counted, named in order along the arm as before.
  • Gallery scripts that carry their own copy of the old search (harmonograph, roseRhodena and others) are unchanged: they are Barry's playpen.
