Lists from the folders (libraryIndex)

Written 5 November 2026. Code: node/libraryIndex.mjs; read by ui/manifest.js and ui/home/homeManifest.js.

Every list Sketchpad shows (Patterns, the three Gallery areas, Utilities Tools and Lab, Figures, Draw's saved settings) and the Home list are worked out from the files in the folders, on request, by the Node service. Before 4 November they came from manifest.json files, and a list was only as right as its manifest.

The rules

  • A category is a folder. The order is that of the library's directoryRegistry.json, then any other folder that holds items, A to Z. Skipped: images, scripts, archive, names starting with "." or "_", and "System Volume Information".
  • An item is a file of the right kind: scripts (.js) for patterns, gallery Scripts and utilities; pictures for Ideabook and gallery Patterns; .json for figures and saved settings. Thumbnails (thumb_*) and the list files themselves are not items.
  • Notes. What a file cannot say about itself (a title other than its name, a Home status, the order) still comes from the folder's manifest.json. An entry whose file is gone is left out. A file with no entry appears after the listed ones, titled by its file name.
  • No watcher. A new file appears the next time the list is read (a reload, or Rebuild). Node's file watching is unreliable on Windows, so it is not used.

The requests

RequestPayloadAnswer
listLibrary{ basedir }, one of the eight libraries{ categories: [name], items: [[entry]] }; items[i] belongs to categories[i]; an entry is { filename, path, title, ...notes }
listHomeItemsnone{ items: [{ file, path, title, status }] }: every item with a status, by title

On the page

ManifestManager.get(basedir) asks for listLibrary for the eight libraries and keeps the answer in its cache exactly as it used to keep manifest data, so no tab changed. Home's loadHomeManifest_async() asks for listHomeItems. Either falls back to reading the files only when there is no service (a read-only copy).

What still writes manifests

Edit Manifest (title, status), Archive, Save figure, Create Pattern and the thumbnail tools still write manifest.json, now as notes. sketchpad.bat no longer runs the manifest maintenance at start-up; Utilities > Rebuild & Validate still runs it.

Tests

npm run test:node builds a scratch library and checks the order, the notes, a file with no entry, an entry with no file, and the refusal of a folder that is not a library. When it was built, every list was compared item by item with the manifests: identical.
