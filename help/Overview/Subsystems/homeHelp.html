Reflections

New reflection... asks for a title, makes a file name from it (letters, digits and spaces kept, spaces as underscores), writes help/Reflections/<name>.html with the title as its <title> through writeHelpFile, and opens the help editor (TinyMCE, ui/helpEditor.js, loaded only then). The title is what the tree shows. Edit opens a chosen reflection in the same editor.

Build Documents

node/copyBuildDocs.mjs empties help/BuildDocs and fills it from docs/: each Markdown file becomes an HTML page (a browser shows Markdown as plain text), converted by a small converter that knows headings, paragraphs, lists, tables, fenced code, quotes and the inline marks; each PDF gets a page that shows it from docs/ in a frame (not copied). Run it after the docs change.

The lists

listHelpTopics { folder } returns every .html under one of the three folders with its title and subfolder, so a new reflection appears at once.
