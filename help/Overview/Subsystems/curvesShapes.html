Curve library and shape palette

Written 5 November 2026. Code: draw/curves.js (the points), draw/ringObject.js (the maker), one small file per object in drawRegistry/. Names: docs/registryNames.md.

Twelve Draw objects, each a curve or shape whose points are stitched one of four ways. In Draw they are in the categories curves and shapes. In Figures, the caption has Rectangle, Polygon and Ellipse buttons beside Line and Parabola, and a Curve... list.

What every one of them has

  • Two handles. The centre moves the whole object. The size handle (starting to the right) resizes it: its distance from the centre is the size. Moving the Size slider moves the size handle.
  • Points: how many points on the curve (3 to 400). These are where nails and discs go.
  • Stitch: Outline (each point to the next), Chords (each point to the one Skip further on), Times table (point i to point i × Factor, round the loop) or All pairs. These are the connectors of draw/connectors.js.
  • Colour and line width. Every line goes through drawLine, so Final mode, figure transforms, print aids and stepping all work.
  • In Figures, the curve's points are one arm: in points mode a disc can be put on any of them, and welded.

How the code is arranged

All twelve are the same kind of object, so one maker builds them: makeRingObject(spec) in draw/ringObject.js. A registry file such as drawRegistry/rose.js is about twenty lines: its name, id, category, the function giving its points (rosePoints from draw/curves.js), and its own setting. Adding a curve means adding a points function to curves.js and a file like these, then a line in main.js and in drawRegistry/drawRegistry.js.

Names

polygon and ellipse are outlines, not to be confused with regularPolygon and inEllipse, which are stitched patterns; archimedeanSpiral names its kind because "spiral" alone is ambiguous. All recorded in docs/registryNames.md (Home > Help > Build Documents).
