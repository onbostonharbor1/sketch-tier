Errors

An error caught at a choke point (a figure layer's draw, the Draw redraw, a tab switch, opening a file) or not caught at all is shown in the red error bar on every tab and written once to utilities/logfiles/errors_<date>.txt. A repeat is counted, not logged again.

A checklist, not a dismissal. Each error in the bar has Tick, and the bar has Tick all. Ticking writes Acknowledged: <where>: <message> to the log. Home > Errors reads every error log and lists each error not yet ticked, across restarts. Show all shows the ticked ones too, greyed. Purge ticked writes Purged: ... lines, after which those errors are not shown at all. The log lines themselves are never removed: a log is history.

errorStates(logTexts) works this out by reading the log lines in order: an error line opens its error (the key is the line without its time and its file:line), an Acknowledged line ticks it, a Purged line removes it, and the same error reported again after a tick is open again.

The checking list

Home > Checklist shows home/checklist.md, a Markdown task list (- [ ] text, ticked - [x] text), so it reads the same in VS Code. Tick or untick an item, Show all, Purge ticked (removes the ticked lines) and Add item each rewrite the whole file through the writeChecklist request, atomically. Lines that are not items (headings, notes) are kept as they are. Each phase adds its hand checks here, with the details in its docs/CHECKLIST_*.md.

One list display

Both subtabs use renderTickList(container, spec): an intro sentence, Show all, Purge ticked (it asks first), an optional Add item box, and the items with checkboxes. Where the items live is the caller's business.
