# Registry names

Registry names are permanent: saved figures refer to them. The rule (Barry, 4 November 2026): derive a new name from the
shape it draws, descriptively. Where a name could be confused with another, it is recorded here. This file appears in
Home > Help > Build Documents.

## Curve library and shape palette (5 November 2026)

| Registry name | Menu name | Category | Note |
|---|---|---|---|
| `rose` | Rose | curves | |
| `lissajous` | Lissajous | curves | |
| `epicycloid` | Epicycloid | curves | |
| `hypocycloid` | Hypocycloid | curves | |
| `astroid` | Astroid | curves | The hypocycloid with 4 cusps, kept as its own object because it has a name of its own. |
| `cardioid` | Cardioid | curves | Also the limacon with loop 1. |
| `limacon` | Limacon | curves | |
| `superellipse` | Superellipse | curves | |
| `archimedeanSpiral` | Archimedean Spiral | curves | **Ambiguous:** "spiral" alone could mean Fermat's or the spiral scripts in `draw/drawSpirals.js`, so the kind is in the name. |
| `rectangle` | Rectangle | shapes | |
| `polygon` | Polygon | shapes | **Ambiguous:** not `regularPolygon`, which draws a stitched polygon (a curve-stitch in each corner). `polygon` is the outline with points along its sides, to be stitched by its Stitch setting or used for nails. |
| `ellipse` | Ellipse | shapes | **Ambiguous:** not `inEllipse`, which stitches across an ellipse of nodes. `ellipse` is the outline. |

## Older names worth knowing

| Registry name | Menu name | Note |
|---|---|---|

| `mysticRose`, `mysticRoseEllipse` | Mystic Rose (circle), (ellipse) | All pairs on a circle or an ellipse. |
